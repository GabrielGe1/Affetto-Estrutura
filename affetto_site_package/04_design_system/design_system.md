# Design system proposto - Affetto

## Direção visual
Clean, premium, local e confiável. Evitar visual de lavanderia industrial genérica ou estética excessivamente popular.

## Paleta de cores proposta

| Token | Hex | Uso |
|---|---|---|
| `--color-cream` | `#F7F3EC` | Fundo principal suave |
| `--color-white` | `#FFFFFF` | Cards e áreas limpas |
| `--color-graphite` | `#2F3437` | Texto principal |
| `--color-muted` | `#6F7477` | Texto secundário |
| `--color-sage` | `#8FA99B` | Cor institucional suave |
| `--color-deep-teal` | `#244E4A` | CTAs e destaques premium |
| `--color-sand` | `#D8C7B0` | Apoio visual e divisórias |
| `--color-gold-soft` | `#B89B68` | Selos, estrelas e pequenos acentos |
| `--color-error-soft` | `#B45C4A` | Alertas discretos |

## Tipografia proposta

### Opção Google Fonts
- Títulos: `Cormorant Garamond` ou `Playfair Display`.
- Texto/interface: `Inter` ou `Nunito Sans`.

### Recomendação prática
Usar `Inter` para todo o site se a prioridade for performance e legibilidade. Usar `Cormorant Garamond` apenas em títulos se quiser um toque mais premium.

## Componentes

- Header fixo simples com logo, links e botão WhatsApp.
- Hero com imagem/vídeo real.
- Barra de provas rápidas.
- Cards de serviços.
- Cards de diferenciais.
- Stepper "Como funciona".
- FAQ accordion.
- CTA fixo no mobile.
- Bloco de avaliações com cards.
- Cards de cidade.

## Regras de UI

- Priorizar espaço em branco.
- Usar imagens reais.
- Evitar banco de imagem artificial.
- Botões grandes no mobile.
- WhatsApp sempre visível.
- Cards com bordas suaves e sombra mínima.
- Sem excesso de texto por seção.
