# Pacote de implementação - Site Affetto Lavanderia

Este pacote organiza os insumos para construir o novo site da Affetto com foco em SEO local, conversão por WhatsApp, clareza de marca e páginas preparadas para tráfego pago.

## Objetivo
Criar um site institucional/comercial enxuto para uma lavanderia especializada em têxteis do lar, priorizando:

1. Cortinas.
2. Edredons e roupas de cama.
3. Retirada e entrega.
4. SEO local em Itapema e Balneário Camboriú.
5. Prova social e dúvidas frequentes.

## Posicionamento correto
A Affetto deve ser comunicada como lavanderia especializada, com processo profissional, produtos biodegradáveis, inspeção cuidadosa e retirada/entrega. Não usar linguagem de solução caseira, misturinha natural, promessa absoluta de remoção de manchas/mofo ou garantia anti-encolhimento.

## Estrutura do pacote

- `01_branding/`: posicionamento, tom de voz, mensagens e regras de linguagem.
- `02_seo_architecture/`: sitemap, URLs, titles, metas, H1s, intenções e links internos.
- `03_pages/`: copy final das páginas prioritárias.
- `04_design_system/`: cores, tipografia, componentes e tokens de design.
- `05_tracking/`: plano de tags, eventos, UTMs e conversões.
- `06_codex/`: prompt e instruções técnicas para Codex construir o site.
- `07_assets_brief/`: checklist de imagens e vídeos necessários.
- `08_next_phases/`: preparação para Google Ads, Meta Ads, MCP e conteúdo.

## Ordem recomendada de implementação

1. Home `/`.
2. `/lavagem-de-cortinas`.
3. `/lavagem-de-edredons`.
4. `/lavanderia-com-retirada-e-entrega`.
5. `/avaliacoes`.
6. `/duvidas-frequentes`.
7. `/lavanderia-em-itapema`.
8. `/lavanderia-em-balneario-camboriu`.

## Observações

- O site deve priorizar mobile.
- WhatsApp é o principal canal de conversão.
- Todo botão de WhatsApp deve ter evento de clique.
- Cada página deve usar mensagem de WhatsApp específica.
- FAQ deve ser em accordion e, se possível, com schema FAQ.
- Páginas devem ser rápidas, visuais e sem excesso de texto.
